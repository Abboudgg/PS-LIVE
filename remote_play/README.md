# Remote Play integration scaffold

هذه المجلدات هي نقطة بداية منظمة لدمج محرك Remote Play لاحقًا. **لا تحتوي هذه المرحلة على محرك Chiaki، ولا تنفذ تسجيل دخول PSN أو الاقتران أو استقبال صوت/فيديو PS5.**

## التصميم المقترح

1. اختيار إصدار ومكوّن مناسب من Chiaki/Chiaki-ng بعد مراجعة الترخيص ومتطلبات البناء.
2. بناء المحرك داخل بيئة تشغيل مدعومة، مع اختبار اتصال PS5 محليًا أولًا.
3. إخراج الفيديو والصوت إلى واجهة محلية آمنة يمكن لـ FFmpeg قراءتها.
4. ربط حالة المحرك بواجهة PS-LIVE API بعد نجاح اختبار فعلي.

## قيود مهمة

- لا تضع بيانات PSN أو رموز الاقتران أو مفاتيح RTMP في GitHub.
- لا تفترض أن Render Web Service مناسبة لاتصال Remote Play؛ يجب اختبار دعم UDP والشبكة والأداء قبل اعتمادها.
- لا يُعتبر اكتشاف PS5 على الشبكة اقترانًا ناجحًا أو دليلًا على استقبال تدفق اللعب.
- ملف `engine.py` حاليًا واجهة حالة تجريبية فقط، وغير موصول بخادم `server.py`.
