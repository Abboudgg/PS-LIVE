# PS-LIVE

مشروع مستقل لبناء جسر بث من PS5 إلى Restream، مع لوحة تحكم عربية.

## الحالة الحالية

هذه مرحلة تأسيسية وليست بثًا مكتملًا:
- خادم HTTP بسيط يعمل على المنفذ الذي توفره بيئة الاستضافة عبر `PORT`.
- `GET /health` لفحص أن الخادم يعمل.
- `GET /status` لقراءة الحالة الحالية.
- `POST /api/stream/start` و `POST /api/stream/stop` للتحكم بخط FFmpeg.
- صورة وصوت PS5 ومحرك Remote Play غير موصولين حتى الآن. لا تعتبر حالة FFmpeg دليلًا على اتصال PS5 أو قبول Restream للبث.

## متغيرات البيئة

أضف القيم التالية في إعدادات الخدمة السرية على Render، ولا تضعها في GitHub أو داخل صفحة الويب:

| المتغير | الغرض |
| --- | --- |
| `PS_LIVE_CONTROL_TOKEN` | رمز طويل وعشوائي لحماية أوامر البدء والإيقاف |
| `PS_LIVE_INPUT_URL` | مصدر فيديو/صوت فعلي متوافق مع FFmpeg (غير متوفر حتى دمج واختبار محرك Remote Play) |
| `RESTREAM_RTMP_URL` | عنوان RTMP الكامل الذي يوفره Restream، ويعامل كسرّ |

لا ترسل هذه القيم في المحادثة ولا تضعها في روابط عامة.

## واجهات API

- `GET /health` — فحص الصحة.
- `GET /status` — حالة الخادم وخط FFmpeg.
- `POST /api/stream/start` — يبدأ FFmpeg بعد إعداد المصدر والوجهة والرمز.
- `POST /api/stream/stop` — يوقف FFmpeg.

تتطلب أوامر التحكم ترويسة:
`Authorization: Bearer <PS_LIVE_CONTROL_TOKEN>`

إذا لم يتم إعداد مصدر PS5، يعيد أمر البدء `409 source_not_configured` بدل الادعاء بأن البث يعمل.

## نشر Render

- أنشئ Web Service منفصلة عن أي مشروع سابق.
- اربط المستودع بهذا الفرع: `setup/render-foundation`.
- اختر بيئة Docker.
- لا تضف مفاتيح RTMP أو أي بيانات PSN إلى المستودع.
- لا نوصي بتشغيل الخدمة على الهواء قبل اختبار مسار Remote Play والشبكة والترميز فعليًا.

## الخطوة التقنية التالية

دراسة ودمج محرك Remote Play مناسب (مثل Chiaki/Chiaki-ng وفق ترخيصه ومتطلبات البناء)، ثم توفير مصدر فيديو/صوت محلي أو شبكي آمن إلى FFmpeg. هذا الدمج يحتاج اختبارًا فعليًا مع PS5؛ ملفات الخادم الحالية لا تنفذ اقتران PSN ولا تتصل بجهاز PlayStation.
